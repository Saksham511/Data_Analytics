# Retail Sales Dashboard
## Project Overview

This project is a Retail Sales Dashboard created using Microsoft Power BI.
The dashboard provides insights into retail sales performance, profit trends, discounts, customer segments, and regional analysis.

The dataset was first cleaned and transformed before creating interactive visualizations for business analysis.

## Data Cleaning & Preparation

Before building the dashboard, the following data cleaning steps were performed:

-Checked for duplicate records
-Standardized numeric formatting
-Corrected data types
-Prepared fields for visualization and analysis

## Visuals

1. Discount Analysis by Customer Segment
Donut chart showing total discount distribution across customer segments:
Consumer
Corporate
Home Office

Insight: Consumer customers received the highest overall discount compared to other segments.

2. Profit Trend by Month
Line chart displaying monthly profit trends.

Insight: Profit increased significantly from February to March for product 'jeans' and region north, indicating better sales performance or improved margins.

3. Sales Amount by Region
Horizontal bar chart comparing sales across regions:
West
North
East
South

Insight: The West and north region generated noticeably more sales revenue.

4. Profit by Region
Horizontal bar chart comparing profit generated by each region.

Insight: The North region contributed the highest profit, while the South region had the lowest profitability for product category 'clothing'.
